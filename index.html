Install

It takes about ten minutes, most of it waiting for downloads.

What you need first

A Mac with Apple siliconM1, M2, M3 or M4. Windows is not ready yet.
MuMu Player ProFree Android emulator for Mac, from its own website.
Clash Royale in MuMuInstalled and signed in. Do not update it: Clash AI works with one exact version (160402012).
About 1 GB freeFor the app and its models.

Step 0: set up MuMu (once)

  1. Install MuMu Player ProDownload it from MuMu's own website (search for "MuMu Player Pro Mac"), open it, and wait for the Android home screen. It may offer to create a device first: accept.
  2. Turn on Root AccessClash AI reads the game from outside it, which needs MuMu's root switch. In MuMu open its settings, go to Other, find Root Access and tick Enable. MuMu restarts the device. (The menu names are the ones in MuMu's own app; if yours looks different, look for "Root Access".) You can check it later: the Setup screen in Clash AI tests it and has a Fix it button.
  3. Install Clash Royale in MuMuOpen the Play Store inside MuMu, install Clash Royale and sign in once. Then turn off its automatic updates and never accept an update prompt: Clash AI works with one exact game version (160402012). If the Play Store gave you a different one, the Setup screen says so and plays nothing.
  4. Leave MuMu openClash AI can start it for you later, but the first time it is easiest to have it running with Clash Royale on the home screen.

Then install Clash AI

  1. Open TerminalPress Command + Space, type Terminal, and press Enter. A window with a text prompt opens. That is all it is.
  2. Paste this one line and press EnterThe beta installer is a short script you can read before you run it: view install.sh.
    curl -fsSL https://github.com/arronwang01/clash-ai-releases/releases/latest/download/install.sh | bash

    It downloads about 400 MB (the app, the models and a private copy of Python) and puts everything in a folder called ClashAI in your home folder. It does not need your password and does not install anything system-wide. It takes a few minutes. You will see each step.

  3. Wait for "Done"The last thing it prints is a quick check of your Mac. A red line there tells you what is missing; the app explains each one.
  4. Open Clash AIOpen the Applications folder inside your home folder (~/Applications) and double-click Clash AI. Because the installer made the app on your own Mac, macOS does not show the "cannot be opened" warning.
    macOS still says it cannot open it

    Go to System Settings → Privacy & Security, scroll to Security, and click Open Anyway next to Clash AI. If that is missing, paste this in Terminal:

    xattr -dr com.apple.quarantine ~/Applications/"Clash AI.app" ~/ClashAI
  5. If macOS asks about incoming connections, click Allow"Do you want the application to accept incoming network connections?" Only the optional phone feature needs this, so you can also click Deny.
  6. Follow the setup screenIt checks MuMu and the game and gives you a button for anything missing. Open Clash Royale in MuMu, switch Autoplay on, then start a Friendly Battle or Training Camp yourself.

To update, run the same line again. To remove it, drag ClashAI (home folder) and Clash AI (in Applications) to the Bin.

Windows is not released yet. It needs testing on a real Windows PC first. This is what the install will look like, so you know what to expect.
  1. Download ClashAI-win.zip and unzip itRight-click the zip, choose Extract All.
  2. Windows will say "Windows protected your PC"This is SmartScreen. It shows for any new app that has not built up a reputation. Click More info, then Run anyway.
  3. Allow it through the firewallIf Windows Defender Firewall asks, tick Private networks and click Allow access. Only the phone feature needs this.
  4. If your antivirus removes itNew unsigned programs are sometimes flagged by mistake. First check the SHA-256 (PowerShell: Get-FileHash .\ClashAI-win.zip) against the one on this page. If it matches, open Windows Security → Virus & threat protection → Protection history, find Clash AI, and choose Restore or Allow on device.

Is it safe?

We cannot prove it to you with a certificate yet. Certificates from Apple and Microsoft cost money, and a new small app does not have a reputation. So here is what we can tell you plainly, and how to check it yourself.

What Clash AI does

It talks to the MuMu emulator through adb, the standard Android tool. It reads the game's state from the emulator's memory and taps the emulated screen. It runs on your computer. It does not ask for your Clash Royale, Google or Supercell password, and it does not touch files outside its own folder and the emulator. The only internet use is checking for updates from GitHub.

How to check what you downloaded

The installer checks the SHA-256 of every file it downloads against the published list and stops if one does not match, so you always get exactly what was published. You can read the installer script before running it (the link in step 2). It also downloads Python from uv and libraries from PyPI, both well-known public sources.

Please be clear about the real risk. Automation tools can break a game's rules, and a game company can act on an account that uses one. Clash AI is meant for Friendly Battles and Training Camp only, but there is no guarantee. Use it at your own risk, and not on an account you cannot afford to lose.

Uninstall

Quit the app, then drag the ClashAI folder (in your home folder) and Clash AI (in ~/Applications) to the Bin. You can also delete ~/Library/Application Support/Clapha. Nothing else is installed on your computer.

FAQ

Why does my computer warn me about the app?

Because it is a new app from a small developer, and Apple and Microsoft only stop warning for apps signed with a paid certificate. The warning does not mean the app is harmful. It means the system does not recognize the developer yet. The steps above show how to open it safely.

Is it free?

Yes. The core app is free. There is an optional VIP plan with extra features such as the on-screen HUD and the phone view.

Which version of Clash Royale does it need?

Exactly version 160402012. If the game updates itself, Clash AI will stop and tell you the version is not supported. Turn off automatic updates for Clash Royale inside MuMu's Play Store, and do not accept an update prompt.

Will it get my account banned?

We cannot promise it will not. Using any automation can break a game's rules. Use it only in Friendly Battles and Training Camp, keep it off your main account, and decide for yourself whether that is acceptable.

How do I update Clash AI?

The app checks for updates by itself and shows a bar at the top when one is ready. Press Update now, then Restart Clash AI. Updates are signed, and the app refuses any that are not. (The very first beta, 0.1.0, cannot do this: run the install line once more to get onto the version that can.)

How do I get VIP?

VIP is a monthly sponsorship of the project. Sponsor on the sponsor page and you are sent a gift code. Open the VIP page in the app, paste it into the gift code box and press Redeem. A code works on one computer, once. There is also a free trial of 5 games inside the app.

The setup screen says something is missing. What do I do?

Each problem has a button or a one-line fix under it. The most common one is that MuMu is not running: press Start MuMu and wait about a minute.

Does it work on Windows or Linux?

Windows is being tested. Linux is not planned.

How do I join the beta or report a problem?

Join the Discord linked on this page once it opens, or contact the person who sent you here. Please include what you were doing and a screenshot of the setup screen.
